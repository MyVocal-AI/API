This page checks that your key works. It only reads your account information: it does not create a
task, a voice or any other resource. No product requires you to complete the others first.

## Step 1: Get your API key

Use a MyVocal account that has API access:

1. Sign in to [MyVocal Account](https://www.myvocal.ai/account).
2. Open Account Info.
3. Copy your API key.

Every endpoint authenticates with the same header, `accessKey: <your_api_key>`. Keep the key on your
server. See [Authentication](/api-reference/authentication) for the details and security practices.

## Step 2: Verify the key

Call [Get account information](/api-reference/user/getInfo). It is a read-only call.

```bash
curl --location 'https://api.myvocal.ai/sound_clone/api/v1/user/info' \
--header 'accessKey: <your_api_key>'
```

A valid key returns `code` `1` and your account data:

```json
{
  "code": 1,
  "message": "Success",
  "data": {
    "plan": "Business",
    "status": "active",
    "resetInDays": 2,
    "benefit": {
      "usedVoices": 146,
      "totalVoices": 150,
      "usedMonthlyChars": 3498604,
      "totalMonthlyChars": 3500000,
      "usedOrderChars": 0,
      "totalOrderChars": 0
    }
  }
}
```

Check `code`, not only the HTTP status: a failed request is also answered with HTTP `200` and a
non-success `code` with a `message`.
