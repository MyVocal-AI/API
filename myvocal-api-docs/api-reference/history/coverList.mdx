---
title: "List Cover history"
api: "GET https://api.myvocal.ai/sound_clone/sound_clone/api/v1/cover/list"
description: "List your AI Cover history records, with a cursor for older records."
---

<sub>**AI Cover · History** · Workflow: [AI Cover quickstart](/guides/cover-quickstart)</sub>

### Header
<ParamField header="accessKey"   type="string" required>
  Your API key. See [Authentication](/api-reference/authentication).
</ParamField>

### Body
<ParamField body="limit" type="number" default="10">
<div>The number of AI Cover history records returned at one time, supporting 10 ~ 1000 data queries at a time.</div>
<div>If this parameter is empty, the default value is 10.</div>
</ParamField>
<ParamField body="startBeforeCoverId" type="string">
<div>If this parameter is provided, we will start tracing back to earlier AI Cover history from this AI Cover item.</div>
<div>If this parameter is empty, then we will default to tracing back directly from the most recent data.</div>
</ParamField>

### Response
<ResponseField name="code" type="number" required>
  Indicates whether the call was successful. 1 if successful.
</ResponseField>

<ResponseField name="message" type="string" >
  When an exception occurs, specific exception information will be provided in the message.
</ResponseField>

<ResponseField name="data" type="object" >
Includes specific data.
    <Expandable title="Toggle object">
      <ResponseField name="hasMore" type="boolean" >
                <div>If there is no earlier created AI Cover item, then callback 1</div>
                <div>If there are still earlier created AI Cover items, then callback 0</div>
            </ResponseField>
      <ResponseField name="earliestHistoryItemId" type="String" >
                The earliest AI Cover id in this response.
        </ResponseField>
        <ResponseField name="list" type="list">
                The AI Cover history records returned by this request.
            <Expandable title="Toggle object">
            <ResponseField name="id" type="string" >
                AI Cover id
            </ResponseField>
            <ResponseField name="title" type="string" >
                AI Cover title
            </ResponseField>

            <ResponseField name="useChars" type="number" >
            character count of this AI Cover item.
            </ResponseField>

            <ResponseField name="channel" type="string" >
            web or api
            </ResponseField>
            <ResponseField name="voiceId" type="string" >
                The voiceId of the voice used to generate this AI Cover
            </ResponseField>
            <ResponseField name="voiceName" type="string" >
                The voice name of the voice used to generate this AI Cover.
            </ResponseField>
            </Expandable>
        </ResponseField>
    </Expandable>
</ResponseField>
