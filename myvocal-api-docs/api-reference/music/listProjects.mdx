---
title: "List music projects"
api: "GET https://api.myvocal.ai/sound_clone/api/v1/music/projects"
description: "Page through the Text-to-Music projects owned by your account."
---

### Header

<ParamField header="accessKey" type="string" required>
  API key for authentication.
</ParamField>

### Query

<ParamField query="page" type="number" required>
  Page number, `>= 1`.
</ParamField>

<ParamField query="pageSize" type="number" required>
  Page size: `10`, `20` or `50`.
</ParamField>

### Response

<ResponseField name="page" type="number">
  Echoed page number.
</ResponseField>

<ResponseField name="pageSize" type="number">
  Echoed page size.
</ResponseField>

<ResponseField name="total" type="number">
  Total number of projects.
</ResponseField>

<ResponseField name="totalPage" type="number">
  Total number of pages.
</ResponseField>

<ResponseField name="list" type="array">
  Entries shaped `{ projectId, name, projectStatus, createdAt, updatedAt }`.
</ResponseField>

<RequestExample>

```bash
curl --location 'https://api.myvocal.ai/sound_clone/api/v1/music/projects?page=1&pageSize=20' \
--header 'accessKey: <your_api_key>'
```

</RequestExample>

### Common errors

- `code = 47001`: `page` is below `1`, or `pageSize` is not `10`, `20` or `50`.
