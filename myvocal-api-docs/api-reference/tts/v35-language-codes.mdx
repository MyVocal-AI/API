Use these codes only with `modelId: "myvocal_v3_5"`. This model has 87 explicit language codes plus Auto. Omitting `language`, or using `auto`, allows automatic language detection; it does not force English.

A language outside this list returns the existing language parameter error (`code = 10004`). Legacy mapped values such as `US_ENGLISH` are not Model V3.5 codes. Declared language support does not imply that every voice and language combination has been tested.
