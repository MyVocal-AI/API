---
title: "Interpretation capabilities"
api: "GET https://api.myvocal.ai/sound_clone/api/v1/interpretation/capabilities"
description: "Read the Interpretation account state, rate, language catalog and supported formats."
---

Read this endpoint first. It publishes the language keys you may request, the accepted input formats, the export formats and the account's rate — instead of hard-coding any of them.

### Header

<ParamField header="accessKey" type="string" required>
  API key for authentication.
</ParamField>

### Response

<ResponseField name="productName" type="string">
  The product name, `Interpretation`.
</ResponseField>

<ResponseField name="rateVersion" type="string">
  Version label of the applicable rate.
</ResponseField>

<ResponseField name="languageCatalogVersion" type="string">
  Version of the language catalog.
</ResponseField>

<ResponseField name="languageCatalogState" type="string">
  `CONFIGURED` when an authoritative language list is configured; `EMPTY` when no usable entries exist, in which case quoting is not available.
</ResponseField>

<ResponseField name="formatCatalogVersion" type="string">
  Version of the accepted-format catalog.
</ResponseField>

<ResponseField name="languages" type="array">
  The language entries: `{ code, name, sourceSupport, ... }`. Use these keys as `targetLanguages` and `sourceLanguage`.
</ResponseField>

<ResponseField name="audioFormats" type="array">
  Accepted audio containers/extensions.
</ResponseField>

<ResponseField name="videoFormats" type="array">
  Accepted video containers/extensions.
</ResponseField>

<ResponseField name="exportFormats" type="array">
  `mp3`, `wav`, `flac`, `mp4`. `mp4` is the composed video and requires a video source.
</ResponseField>

<ResponseField name="maxSourceBytes" type="string">
  Maximum declared upload size, as a **string**. Convert before comparing.
</ResponseField>

<ResponseField name="planRates" type="array">
  `{ planKey, charactersPerMinutePerLanguage }` entries.
</ResponseField>

<ResponseField name="quoteTtlSeconds" type="number">
  How long a quote stays valid. Currently `600`.
</ResponseField>

<ResponseField name="account" type="object">
  `{ planKey, accessState, entitlementVersion, charactersPerMinutePerLanguage, availableCharacters, balanceState }`. `availableCharacters` is a **string** or `null`.
</ResponseField>

<ResponseField name="stageAvailability" type="object">
  Availability flags for the public stages. Internal development identifiers are not published here.
</ResponseField>

### Common errors

- `code = 401`, `"Key verification failed"`: the `accessKey` is missing, invalid or disabled. Returned with HTTP `200` and **no** `data`.
- `code = 47128`: the account's plan is not entitled to generate (for example `FREE`).
- `code = 47119`: an ENTERPRISE account has no configured contract rate. Interpretation does **not** fall back to a default rate.
