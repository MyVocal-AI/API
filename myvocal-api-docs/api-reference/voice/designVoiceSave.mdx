title: "Voice Design Save (temporarily unavailable)"
description: "The voice design API is temporarily unavailable."
---

<Warning>
The voice design API is **temporarily unavailable**, including this save endpoint. It cannot be called at this time.
</Warning>

- Saving a designed voice is unavailable, because a designed voice cannot be created while the feature is withdrawn.
- A call to this endpoint answers with the standard JSON envelope and `code` `10029` (`The voice design API is temporarily unavailable.`).
- The previous request fields and examples have been removed from this page so that a stale link cannot be mistaken for the current contract.

A voice you already saved remains fully available: it is still returned by [List Voices](/api-reference/voice/list) and still works with Text-to-Speech.

To add a new voice, use [Add TTS Voice](/api-reference/voice/addTTSVoice) or [Add Cover Voice](/api-reference/voice/addCoverVoice) instead.
