description: "The voice design API is temporarily unavailable."

<Warning>
The voice design API is **temporarily unavailable**. This endpoint cannot be called at this time.
</Warning>

- There is no supported request or response contract for this feature while it is withdrawn, so do not build an integration against it.
- A call to this endpoint does not return a designed voice. It answers with the standard JSON envelope and `code` `10029` (`The voice design API is temporarily unavailable.`).
- The previous request fields, response headers and examples have been removed from this page so that a stale link cannot be mistaken for the current contract.

A voice you already created remains fully available: it is still returned by [List Voices](/api-reference/voice/list) and still works with Text-to-Speech.

To add a new voice, use [Add TTS Voice](/api-reference/voice/addTTSVoice) or [Add Cover Voice](/api-reference/voice/addCoverVoice) instead.
