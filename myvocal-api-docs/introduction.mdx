All MyVocal products share one public host, `https://api.myvocal.ai`, and one `accessKey` request header.
Pick the product you need; each card starts at that product's shortest working path. You do not need to
create a voice or try every product first.

## Voices and TTS models

<a id="core-workflow"></a>

- Text to Speech and AI Cover take a `voiceId`. Cloning your own voice is optional; see
  [How to use voices](/guides/voice-quickstart). The other products do not use voices.

<a id="how-tts-models-work"></a>

- Text to Speech uses the default model path when you omit `modelId`, or the model you name with a public
  `modelId` such as `myvocal_v3`. See [TTS Models & Migration](/api-reference/tts/models) for the list.

<a id="synchronous-streaming-and-asynchronous-apis"></a>

## How results come back

Products return results in different ways. Use the mechanism of the product you integrate:

| Product | How you get the result |
|---|---|
| Text to Speech, Voice cloning (TTS voices), account information | In the HTTP response |
| Speech to Text — Batch | Poll the transcription; an optional [signed completion notification](/guides/stt-batch-quickstart#completion-notifications) is available |
| Speech to Text — Real-time | WebSocket events, then `finish` |
| AI Cover, Cover voice creation and improvement | [Cover callbacks](/callback) to your `callbackUrl` |
| Text to Music, Interpretation | Poll the project or job; see [Async jobs, polling and retries](/guides/async-jobs-and-retries) |

For how Speech to Text, Text to Music and Interpretation charge Characters, see [Characters and billing](/guides/characters-and-quotes).
Your plan and balance are returned by [Get account information](/api-reference/user/getInfo).
