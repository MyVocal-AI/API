MyVocal real-time Speech to Text — browser client

This page records microphone audio and streams it to MyVocal. It exchanges your API key once for a short-lived ticket, then connects the socket with the ticket, so the long-lived key never appears in a URL. Nothing is sent to any provider from the browser. The session declares the microphone's real sample rate, and Stop drains the audio worklet so the tail is not lost.
